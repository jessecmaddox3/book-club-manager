# Security reports

Please report a suspected vulnerability privately through this repository's GitHub **Security → Report a vulnerability** page. Include reproduction steps with invented data. Do not put credentials, real member records, or working access tokens in a public issue.

Production membership is explicitly linked to verified Auth user UUIDs. The local persona picker is intentionally account-free and must remain loopback-only. The same database commands enforce current roles, revisions, and ballot state in both modes.

This is personal software shared for reuse. Run a current supported release, keep private backups, and verify your own hosting and account setup.
