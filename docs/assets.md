# Assets and credits

> **TL;DR:** The code is MIT licensed. Three bundled fonts retain their SIL Open Font Licenses. The hero illustration was generated for this public project and contains no personal photo or club data.

## Illustration

`docs/assets/book-club-manager-hero.png` was generated with ChatGPT image generation for this release. It is a playful book-club introduction showing books, chairs, a table, and drinks. No original member photograph, club logo, or private source image was supplied. It is included as an unedited generated PNG.

## Fonts

The app serves its fonts locally. There is no runtime request to a font provider. These files came from the Google Fonts repository, unmodified; exact SHA-256 values and source Git blob IDs are recorded in [font-provenance.json](font-provenance.json).

| Font | Included license |
| --- | --- |
| Playfair Display | [SIL Open Font License](../licenses/fonts/playfair-display-OFL.txt) |
| Inter | [SIL Open Font License](../licenses/fonts/inter-OFL.txt) |
| JetBrains Mono | [SIL Open Font License](../licenses/fonts/jetbrains-mono-OFL.txt) |

The font license files apply to the fonts independently of the project MIT license. Package dependencies retain their own licenses; the lockfile records the exact dependency graph for this release.

## Books and covers

The demo book catalog is fictional. Its default cover blocks use text and styling, not copied book artwork. Optional local cover files must be supplied by the installation owner with appropriate rights. Cover files are public static assets; see [privacy](privacy.md).
